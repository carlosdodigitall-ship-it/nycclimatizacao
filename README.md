# NYC Climatização

Landing page comercial responsiva em português para refrigeração e climatização, com visual diurno em azul e branco.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Antes de publicar

- Confirmar o número oficial de WhatsApp e configurar o envio real do formulário.
- Confirmar telefone, regiões atendidas, horários e serviços oferecidos pela empresa.
- Substituir as imagens de referência por fotos autorizadas dos serviços/equipe, quando disponíveis.
- Testar links, formulário e versão móvel em produção.

O formulário atual prepara um arquivo local com os dados preenchidos; ele não envia dados a um servidor nem armazena informações. Não anuncie o formulário como envio automático até configurar e testar um canal real de contato.
